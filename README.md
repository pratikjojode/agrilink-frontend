# AgriLink Frontend

Frontend for the **AgriLink** demo website.

This is a **React + Vite** application that serves as the user interface for AgriLink. It uses:

- React 19
- Vite as the build tool
- TailwindCSS for styling
- React Router for client-side routing
- lucide-react for icons

---

## 🚀 Getting Started (Local Development)

### 1. Install dependencies

```bash
npm install
```
